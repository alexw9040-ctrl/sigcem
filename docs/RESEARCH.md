# Fontes de referência do SIGCEM

A implementação foi orientada por fontes oficiais e referências técnicas consultadas durante o desenho do sistema. Elas não substituem a validação do jurídico municipal nem o regulamento local.

- [ANPD — Guia orientativo de tratamento de dados pessoais pelo Poder Público](https://www.gov.br/anpd/pt-br/documentos-e-publicacoes/guias-e-orientacoes/guia_poder_publico.pdf): base para minimização, finalidade, segurança, transparência e governança de dados pessoais.
- [Planalto — Lei nº 13.709/2018 (LGPD)](https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/l13709.htm): referência legal para tratamento e proteção de dados pessoais.
- [Planalto — Lei nº 12.527/2011 (LAI)](https://www.planalto.gov.br/ccivil_03/_ato2011-2014/2011/lei/l12527.htm): referência para acesso à informação pública, ressalvados dados pessoais e hipóteses legais de restrição.
- [Planalto — Lei nº 14.133/2021](https://www.planalto.gov.br/ccivil_03/_ato2019-2022/2021/lei/l14133.htm): referência para planejamento e contratação pública, quando o SIGCEM for objeto de contratação.
- [CONAMA — Resolução nº 335/2003](https://conama.mma.gov.br/?option=com_sisconama&task=arquivo.download&id=335): referência ambiental para implantação e operação de cemitérios.
- [IBGE — Censo 2022, população de Ararendá–CE](https://www.ibge.gov.br/cidades-e-estados/ce/ararenda.html): contexto demográfico do município de referência.

As telas públicas não expõem CPF, RG, documentos pessoais ou informações familiares. Os modelos de taxas, prazos, situações e documentos permanecem configuráveis, pois dependem da legislação e dos atos municipais aplicáveis.
